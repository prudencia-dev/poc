# POC Machine Learning & Deep Learning

Depot de demonstration pour la certification **Developpeur en Intelligence
Artificielle** :

- un POC Machine Learning de classification de severite d'incidents IA ;
- un POC Deep Learning de fine-tuning de JuriBERT pour PRUDENCIA.

Chaque POC est fourni sous forme de script Python executable bloc par bloc
(``# %%``) et de notebook Jupyter synchronise.

La documentation d'installation, les choix techniques, les commandes et les
limites sont presentes dans [notebooks/README.md](notebooks/README.md).
